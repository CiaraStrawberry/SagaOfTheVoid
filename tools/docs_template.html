Project record

Saga of the Void, remade

A 2017 VR space strategy game, recovered from its shipped build after the project files were lost, and rebuilt in Unity 6 LTS as a mouse-and-keyboard game: real 3D ships fighting on a flat battlefield under an angled strategy camera.

    How to run things

    Play the skirmish

    Editor: open the game folder in Unity Hub with Unity 6000.3.28f1, open Assets/Scenes/Skirmish.unity, press Play. Test build: builds/Skirmish/SagaRemake.exe.

    Play in the browser

    Unity.exe -batchmode -quit -projectPath game -buildTarget WebGL -executeMethod BuildScript.BuildWeb -logFile tools/buildweb.log
python tools/serve_web.py        # then open http://127.0.0.1:8000

    Build the test executable

    "C:\Program Files\Unity\Hub\Editor\6000.3.28f1\Editor\Unity.exe" -batchmode -quit -projectPath game -executeMethod BuildScript.BuildWindows -logFile tools/build.log

    Run the tests

    Unity.exe -batchmode -projectPath game -runTests -testPlatform EditMode -testResults tools/tests_edit.xml
Unity.exe -batchmode -projectPath game -runTests -testPlatform PlayMode -testResults tools/tests_play.xml

    Edit-mode tests check the battle rules. The Play-mode test plays a real skirmish and saves screenshots to tools/preview/skirmish_*.png.

    Record a battle video

    Unity.exe -batchmode -quit -projectPath game -executeMethod BattlePreview.Record -quick
ffmpeg -framerate 60 -i tools/preview/frames/%05d.jpg -c:v libx264 -crf 26 -pix_fmt yuv420p -r 30 tools/preview/battle.mp4

    -quick is an 8 v 8 fight capped at 75 s, for fast checks. Without it, 18 v 18 for showcase videos.

    Rebuild data, ships and these docs

    python tools/make_data.py        # ships.json, weapons.json from the recovery catalog
python tools/make_campaign.py    # campaign.json from the 2017 mission list
Unity.exe -batchmode -quit -projectPath game -executeMethod ShipModelBuilder.BuildShips   # ship prefabs + ShipLibrary
python tools/make_docs.py        # this page

    How battles work

    Battle rules

    The rules run in game/Assets/Scripts/Sim (no Unity dependency), sixty steps a second, on a flat plane. They follow the 2017 code, with the changes listed under Decisions.

    Movement

    Ships turn toward their goal and thrust forward. Big ships only thrust when the goal is within 45° of the nose, accelerate at 240 units/s², and brake inside 300 units. Fighters and corvettes always fly flat out, so they loop around their target. Big ships push apart inside 300 units.

    Holding at range

    Big ships stop just inside the range of their shortest gun when an enemy is near, so every gun fires. A plain move order from the player goes exactly where told.

    Targeting

    Once a second each ship picks a target with its first gun: the ordered target if it's in range, else the nearest ship of the size the gun prefers, else the nearest enemy. Missiles and bombs never target fighters. Shield repair targets the nearest damaged friend.

    Firing

    Each gun fires in bursts: shots per burst shots, time between shots apart, then waits burst wait. A shot that rolls a hit lands after its travel time (distance ÷ 440 + 0.5 s; lasers 3 s).

    Damage

    While shields are up they soak whole hits, and overflow is lost. Then armour takes the damage. Fighters and corvettes ignore the number: each hit knocks out a step (fighters 70/50/30/10%, then gone).

    Dogfights

    Enemy fighter squadrons within 1,500 of each other lock into a fight around a fixed point (700 radius). Any number of squadrons from both sides can be in one fight; they target enemies in the same fight first. It ends when only one side is left. Fighters turn on a 380-wide circle.

    Shield field

    A Support Frigate recharges friendly non-fighter ships within 1,500 units at 1% of their maximum shield per second, even from broken. Fields don't stack.

    Computer player

    Once a second: with more than 4 ships the whole fleet heads for the enemy nearest its first ship, keeping formation (fighters chase their own targets). With 3 or fewer it falls back home, and turns to fight if an enemy comes within 1,000. It buys from the 2017 weighted list, which leans toward frigates; above 100 on a 0–199 roll it repeats its last buy.

    Economy

    You start with 1,500 credits, the computer with 1,000. +30 a second while under 7,000 (computer: ×0.6 easy, ×0.9 normal, ×1.4 hard). Ships are paid for when queued, build one at a time (same kind stacks), and arrive beside the fleet. Kills pay a third of the ship's cost to whoever landed the last hit. Fleet limit 22 in a 1v1.
